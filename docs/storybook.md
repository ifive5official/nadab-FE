# 광고 UI Storybook

실제 광고 시청·로그인 없이 현재 광고 화면의 디자인을 확인합니다.

```sh
pnpm install --frozen-lockfile
pnpm storybook
```

브라우저에서 `http://localhost:6006`을 엽니다. 좌측 **광고 → 보상 팝업 / 개인정보 설정**에서 상태를 선택합니다.

## 확인 방법

- 기본 화면은 모바일 390px, 라이트 모드입니다. 상단 도구에서 360·390·430px 및 라이트/다크 모드를 바꿀 수 있습니다.
- **Controls**에서 금액, 오류 문구를 바꿉니다. 비용·잔액·부족분은 경계 사례도 확인할 수 있도록 각각 독립적으로 수정합니다. 대상 기능은 물어보기 대화권 충전이며 기본값은 200·30·170입니다.
- **Actions**에서 취소·광고 보기·다시 확인·개인정보 설정 클릭을 확인합니다. 부족 안내에서는 **아니요 / 네**로 응답합니다. 디자인 확인 중 화면이 사라지지 않도록 버튼은 상태를 전환하지 않습니다. 다른 상태는 좌측 스토리 또는 phase Control로 선택합니다.
- 광고 시청·후속 기능 실행 상태에서는 앱과 동일하게 취소 버튼과 Escape 닫기를 제공하지 않습니다.
- 숨김 스토리에서는 빈 화면이 정상입니다. 개인정보 설정의 처리 중 상태는 기존 앱과 같은 문구를 유지하며 버튼만 비활성화합니다.

| 그룹 | 상태 |
| --- | --- |
| 부족 안내 | 대화권 충전 |
| 진행 | 잔액 조회 / 광고 준비 / 광고 시청 / 보상 확인 / 후속 기능 실행 |
| 예외 | 지급 지연 / 세션 만료 / 광고 실패 / 일반 오류 |
| 경계 | 숨김 / 긴 오류 문구 / 큰 금액 |
| 개인정보 설정 | 기본 표시 / 처리 중 / 미지원 숨김 |

## 구성과 범위

앱과 Storybook 모두 `AdRewardDialogView`, `AdPrivacySettingsView`를 사용하므로 같은 마크업·버튼·폰트·색상 토큰이 적용됩니다. 앱에서는 기존 연결 컴포넌트가 SDK·스토어·인증·앱 생명주기를 관리합니다. Storybook은 화면 컴포넌트와 고정 예시 데이터만 가져옵니다.

`.storybook`의 독립된 Vite 설정을 사용하며 앱의 라우트 자동 생성, API 프록시, Capacitor 동기화, 운영 광고 활성화를 실행하지 않습니다. 로컬 앱용 `VITE_` 환경변수도 Storybook 클라이언트에 노출하지 않습니다. 실제 네이티브 광고 화면과 ATT·UMP 동의창은 실기기에서 확인해야 합니다.

## 정적 빌드와 검증

```sh
pnpm build-storybook
pnpm exec vitest run src/features/ad-rewards
pnpm exec tsc --noEmit
pnpm build
```

정적 결과물은 `storybook-static/`에 생성되고 Git에서 제외됩니다. 별도 호스팅이나 스토어 배포는 수행하지 않습니다.
